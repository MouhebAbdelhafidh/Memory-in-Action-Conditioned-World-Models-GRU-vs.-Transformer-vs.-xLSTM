# Memory in Action-Conditioned World Models: GRU vs. Transformer vs. xLSTM
A small-scale, single-GPU research project that builds an action-conditioned world model, uses it to plan by imagination, and tests which sequence architecture keeps the most useful memory in partially observable tasks, at equal parameter count and bounded VRAM.<br/>
## Main question
In partially observable tasks, which sequence core gives an action-conditioned world model the most useful belief state over long horizons per unit of parameter count and VRAM?
